Cómo colocar un TAG de TelePASE

Guía paso a paso para dar de alta la colocación de un TAG en el sistema web de Unipase, desde que buscás al cliente hasta que le explicás cuándo va a funcionar.

  1. 1Nueva colocación
  2. 2Buscar cliente
  3. 3Revisar datos
  4. 4Validar el pago
  5. 5Abrir colocación
  6. 6Completar formulario
  7. 7Aceptar
  8. ✓Entregar el TAG

Antes de empezar

  • Es un sistema exclusivamente comercial.
  • No es una app: se entra desde un link web en el navegador.
  • El usuario y la contraseña de la sucursal son confidenciales. No se comparten.
  • En la práctica, lo que te interesa son las adhesiones: cada cliente con sus vehículos.

Se puede

  • Buscar adhesiones
  • Colocar TAGs
  • Ver mi stock

No se puede

  • Cambiar medios de pago
  • Descargar facturas
  • Cambiar titularidad
  • Ningún trámite administrativo

Si el cliente pide algo de la columna roja, derivalo al canal administrativo. No se resuelve desde este sistema.

1
Paso 1

Entrá a Nueva colocación

En el menú de la izquierda, dentro de Colocaciones y adhesiones, hacé clic en Nueva Colocación.

Se abre la pantalla Búsqueda por DNI/Dominio/Tag.

2
Paso 2

Buscá al cliente

Completá un solo campo y tocá Buscar. Usá este orden:

  1. Primero, por Dominio: la patente del vehículo, por ejemplo QQQ111. Es la forma recomendada.
  2. Si tiene más de un dominio, por Documento: cuando el cliente tiene más de un vehículo a su nombre, buscá por DNI o CUIT, por ejemplo 30714783129, para ver todos sus vehículos juntos.

El campo Tag número sirve solo si el cliente ya tiene un TAG.

¿No aparece? Si el cliente no existe, usá Nuevo Cliente/Adhesión para darlo de alta.
3
Paso 3

Revisá los datos del cliente

Aparecen los Datos cliente: nombre o razón social, documento, tipo de cliente (particular o empresa), condición de IVA, teléfonos y email.

Confirmá con el cliente que sean correctos. Más abajo, en la pestaña Vehículos, está la lista de sus autos.

4
Paso 4

Validá el pago

Antes de colocar, el TAG tiene que estar pago. En la fila del vehículo, a la izquierda, hay tres íconos que vas a usar:

1
Tarjeta con @Envía al cliente un correo con el link para pagar con Mercado Pago.
2
NubeValida el pago.
3
AutitoAbre la colocación. Se usa recién con el pago validado (paso 5).

El cliente ya pagó

  1. Tocá el ícono de la nube ②.
  2. Seguí con el paso 5.

Todavía no pagó

  1. Tocá la tarjeta con @ ①. Se abre la ventana Email Parameter.
  2. Escribí el email del cliente y tocá Aceptar. Le llega el link de pago.
  3. El cliente paga con el link.
  4. Volvé a la fila y tocá la nube ② para validar.
  5. Seguí con el paso 5.
Ojo: revisá con el cliente que el email esté bien escrito. Si tiene un error, el link de pago no le llega.
5
Paso 5

Abrí la colocación del vehículo

Con el pago validado, buscá en la lista el vehículo que no tiene TAG (la columna TAG está vacía). Cómo leer la lista del ejemplo:

VehículoTAGQué significa

En esa fila, hacé clic en el ícono del autito, el segundo empezando por la izquierda. Se abre la ventana Colocación.

6

7
Paso 7

Revisá y tocá Aceptar

Antes de confirmar, repasá esta lista con el cliente adelante:

Con todo en orden, tocá Aceptar. La colocación queda registrada.

✓
Entrega

Dónde va el TAG en el parabrisas

  • Va del lado de adentro del parabrisas, siempre.
  • Se pega 3 dedos debajo del espejo retrovisor.
  • Si el parabrisas tiene una banda de polarizado oscuro arriba, el TAG va debajo de esa banda.
Recomendación: entregá el TAG en mano y explicale al cliente estas tres indicaciones. Si el cliente prefiere, lo colocás vos.
Después de la colocación

El TAG no funciona al instante

El TAG tarda entre 72 y 96 horas hábiles en activarse, porque la colocación pasa por varias empresas antes de llegar a las autopistas. Avisale siempre al cliente.

¿El cliente viaja antes de que se active?

  1. Entra a la página de TelePASE con su usuario.
  2. Carga el lector de patente como forma de chequeo.
  3. En la cabina del peaje le leen la patente hasta que el TAG esté activo.

Cuando el TAG se activa, pasa a leerse solo. No hace falta hacer ningún cambio: es automático.
